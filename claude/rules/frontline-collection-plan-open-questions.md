# Frontline Collection Plan: Ask the Open Questions

The Frontline Gaming hobby collection restructure has unknowns that only the user's team can answer, such as tax, feeds, marketplace apps and purchasing. They are tracked in one place so they don't get forgotten:

`C:/Users/cjswa/Documents/jadepuma/shop-scripts-toolkit/frontline-gaming-taxonomy-audit/collection-restructure-plan.md`, section **"Open questions"** (Q-numbered tables with a Status column).

## When this applies

Any work on the Frontline Gaming (frontlinegaming.myshopify.com) hobby collections or that plan, including:

- writing or running scripts that change products (categories, category metafields, tags)
- changing collection rules or creating collections from the plan
- starting the deferred work: product type, vendor, or the optional cleanup
- updating or reviewing the plan itself

## Required behavior

1. **Read the plan's Open questions section first.** The plan is the source of truth for the list; do not rely on memory of it.
2. **Before starting a step, ask every question still marked `Open` that blocks that step** (see each question's "Blocks" column). Ask them in chat, all together, before doing the work. Follow the notify rule: plain sentence case plus one Windows toast.
3. **Don't run the blocked step until those questions are answered**, unless the user explicitly says to go ahead without an answer. If they do, note that in the plan.
4. **Record each answer in the plan.** Set the status to `Answered`, add the answer and the date (YYYY-MM-DD), and update any section the answer changes.
5. **When work on the plan begins in a new conversation,** list the remaining `Open` questions briefly, even if the current step isn't blocked by them, so they stay visible.
6. **Add new unknowns to the section as new Q-numbered rows.** Don't leave them only in chat.

## Standing scope for this rollout (don't violate while waiting on answers)

- Only change categories and category metafields, and add tags.
- Never change product type or vendor, and never remove tags or other product data, unless the user explicitly approves that specific change.
- Append to list-type category metafields (such as Paint type); never replace existing values.
